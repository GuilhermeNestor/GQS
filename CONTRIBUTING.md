# Orientacoes de contribuicao

- Todos os commits de refatoracao devem preservar o comportamento do sistema.
- Divida responsabilidades entre entidade, servicio e interface.
- Use nomes descritivos e mantenha o codigo Python compativel com o projeto.
- Execute a validacao de comportamento antes de enviar as alteracoes.
- Nao inclua artefatos de bytecode, testes temporarios ou arquivos gerados no historico.
